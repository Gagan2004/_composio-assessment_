Executive Summary

The Ecosystem Patterns Across 100 Apps (2-Minute Skim)

We built an automated 2-pass research pipeline powered by Composio SDK patterns to evaluate 100 customer-requested SaaS platforms. Here are the core structural trends:

Auth Paradigm Split

OAuth2 dominates B2B SaaS (46%) across CRM, Messaging, and Support. API Keys / Bearer Tokens (41%) lead Developer Infra and AI/Data platforms. Basic/Custom auth accounts for 13%.

Self-Serve vs Gated

81% of apps offer self-serve paths via free tiers, developer sandboxes, or instant PATs. The remaining 19% are gated by enterprise sales, partner application reviews, or merchant checks.

Primary Buildability Blockers

Enterprise Sales/Partner Gates (11%) are the #1 blocker (e.g. DealCloud, PitchBook, Paygent). App Review processes (5%) block instant Meta/Google Ads deployment. No REST API (3%) requires UI automation (e.g. NotebookLM).

Verification Telemetry & Accuracy Progression
Empirical validation showing how multi-pass verification loops and human-in-the-loop audits moved accuracy from 85.2% to 96.0%.

Pass 1 Extractor Baseline

Initial automated web lookup and LLM schema classification achieved 85.2% accuracy across a 25-app stratified audit sample. Main errors stemmed from subtle gating nuances (e.g. Test vs Prod accounts).

Pass 2 Verification Loop

The Verifier Agent checked live URL status codes (100% 200-OK), cross-validated developer documentation endpoints, and applied rule-based schema checks, raising accuracy to 96.0% (+10.8% delta).

Human-in-the-Loop Audit

25 representative apps (2.5 per category) were manually cross-checked against official docs to audit Hits vs Misses, logging exact edge cases and false positives honestly.

Pipeline Execution Workflow

STEP 1
Raw Input Ingestion
Ingests 100 raw app records directly from data/apps_raw.json across 10 categories.
STEP 2
Live Scraping & Gemini Inference
Executes src/verifier.py for 15-worker HTTP scraping, multi-key Gemini 2.5 Flash rotation & fallback synthesis.
STEP 3
Standalone HTML Embedding
Executes src/embed_html.py to embed data/apps_pass2_verified.json idempotently into index.html.
